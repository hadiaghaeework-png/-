# داشبورد تحلیل نمرات کنترل کیفیت

ابزار تحت وب (HTML/JS، بدون بک‌اند) برای استخراج و تحلیل نمراتی که تیم کنترل کیفیت (QC) به کارشناسان تماس می‌دهد.

فایل اکسل خروجی فرم QC هر تیم را بارگذاری می‌کنید و ابزار به‌صورت خودکار نمرات را استخراج، بازمحاسبه و تحلیل می‌کند.

## اجرا

فایل `index.html` را مستقیم در مرورگر باز کنید، یا یک سرور محلی بالا بیاورید:

```bash
python3 -m http.server 8080
# سپس http://localhost:8080
```

> برای کار کردن دکمه «بارگذاری داده نمونه» باید از طریق سرور محلی باز شود (نه `file://`).

تمام پردازش داخل مرورگر انجام می‌شود و هیچ فایلی به سرور ارسال نمی‌شود.

## تیم‌های پشتیبانی‌شده

| تیم | سهم نمره کیفی | سهم نمره QA | فایل نمونه |
|---|---|---|---|
| BNPL – هپی کال | ۸۰٪ | ۲۰٪ | `samples/qc_bnpl_happycall_sample.xlsx` |
| BNPL – وصول مطالبات (End User) | ۸۰٪ | ۲۰٪ | `samples/qc_bnpl_enduser_sample.xlsx` |
| BNPL – فروش اقساطی | ۹۰٪ | ۱۰٪ | — |
| MLM – بازاریابی شبکه‌ای | ۸۰٪ | ۲۰٪ | `samples/qc_mlm_sample.xlsx` |

ضرایب و شرح هر معیار دقیقاً از فایل‌های «المان های کنترل کیفیت» در پوشه‌ی `docs/` استخراج شده است.

## قواعد نمره‌دهی

مقدار هر معیار در فایل اکسل:

| مقدار | معنا |
|---|---|
| `1` | معیار به‌درستی رعایت شده |
| `0` | معیار رعایت نشده یا فراموش شده |
| `-` | معیار در ارزیابی بی‌اثر است |

- معیارهای `-` و معیارهای ثبت‌نشده از **مخرج** حذف و نمره نرمال‌سازی می‌شود.
- نمره نهایی = (درصد بخش کیفی × سهم کیفی) + (درصد بخش QA × سهم QA).
- ثبت هر **رد لاین** نمره کل آن تماس را **صفر** می‌کند.
- مبنای گزارش‌ها ستون `score` (نمره ثبت‌شده تیم QC) است؛ نمره بازمحاسبه‌شده بر اساس ضرایب سند نیز کنار آن نمایش داده می‌شود تا مغایرت‌ها قابل ردیابی باشد.

## ساختار فایل ورودی

ستون‌های شناسنامه‌ای مشترک:

```
lead_id, lead_name, lead_phone, action_date, action_name,
tele_expert_name, qc_expert_name, form_created_date, score,
Red_line, Red_line_Reason, QC comment, Listening time (second)
```

پس از آن، ستون هر معیار با کلید انگلیسی خودش (مثلاً `agent_introduction_and_role`).
لیست کامل کلیدهای هر تیم از طریق لینک «مشاهده المان‌ها و ضرایب» در کارت همان تیم قابل مشاهده است.

ستون `tele_expert_name` برای تفکیک کارشناسان **الزامی** است. اگر معیاری در فایل نباشد، ابزار هشدار می‌دهد و ضریب آن را از محاسبه حذف می‌کند.

## قابلیت‌ها

- **بارگذاری فایل**: کارت جداگانه برای هر تیم با drag & drop؛ تشخیص خودکار عدم تطابق فایل با تیم انتخابی.
- **تحلیل کلی**: KPIها، مقایسه تیم‌ها، توزیع نمرات، روند زمانی، ضعیف‌ترین معیارها.
- **کارشناسان**: رتبه‌بندی، تفکیک نمره کیفی/سیستمی، کارنامه فردی با توصیه‌های خودکار بهبود.
- **المان‌های ارزیابی**: درصد رعایت هر معیار، امتیاز از دست‌رفته، ماتریس کارشناس × معیار.
- **رکوردها**: مرور تک‌تک ارزیابی‌ها با ریز نمرات هر معیار.
- **فیلترها**: تیم، کارشناس، ارزیاب QC، بازه تاریخ، حداقل نمره، جستجوی متنی.
- **خروجی**: CSV (کارشناسان / معیارها / رکوردها) و چاپ به PDF.

## افزودن تیم جدید

کافی است یک آبجکت به آرایه‌ی `TEAMS` در `assets/js/teams.js` اضافه کنید:

```js
{
  id: 'team_id',
  group: 'BNPL',
  name: 'نام فارسی تیم',
  nameEn: 'English Name',
  short: 'نام کوتاه',
  color: '#2563eb',
  icon: '☎',
  qualityShare: 80,   // سهم نمره کیفی
  qaShare: 20,        // سهم نمره QA
  sample: 'samples/....xlsx',   // یا null
  deck: 'docs/....pptx',        // یا null
  description: 'توضیح کوتاه',
  criteria: [
    { key: 'excel_column_key', label: 'عنوان معیار', weight: 10,
      section: 'quality',       // یا 'qa'
      desc: 'شرح معیار',
      aliases: ['نام_جایگزین_ستون'] }   // اختیاری
  ],
  redLines: ['...']
}
```

کارت تیم، فیلترها، نمودارها و گزارش‌ها به‌صورت خودکار ساخته می‌شوند.

## ساختار پروژه

```
index.html
assets/
  css/style.css
  js/teams.js       ← پیکربندی تیم‌ها، معیارها و ضرایب
  js/analyzer.js    ← موتور تحلیل (پارس، نمره‌دهی، آمار)
  js/app.js         ← رابط کاربری، نمودارها، خروجی‌ها
  vendor/           ← SheetJS و Chart.js (آفلاین)
samples/            ← فایل‌های نمونه ورودی
docs/               ← اسناد المان‌های کنترل کیفیت (PPTX)
```
